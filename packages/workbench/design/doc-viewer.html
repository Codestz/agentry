markdown-serializer + golden corpus

in progress owns web/doc/markdown-serializer.ts phase 3

Goal

Build the ONE markdown↔Tiptap serializer module plus the golden round-trip corpus that asserts tiptapToMd(mdToTiptap(x)) === normalize(x) over real .agentry artifacts. The tripwire against silent corruption.

Approach

Frontmatter is split off before the editor; only body round-trips. One module owns both directions. The comment mark serializes to nothing.

mdToTiptap(body) → ProseMirrorDoc
tiptapToMd(doc)  → body
normalize(body)  → canonical, byte-stable

Acceptance

  • Round-trip identity holds for every corpus artifact.
  • A deliberately-lossy mapping fails a golden test.
