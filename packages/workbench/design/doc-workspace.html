Spec — @agentry/workbench

Intent. A per-project local web app where a human interacts with a run's work — read/edit/comment/approve the .agentry artifacts and watch/steer the agents — rendered over the FLOW v1 file seams.

Acceptance criteria

  • Works home lists every run with status/shape/agents.
  • Live renders the run as a React Flow graph with typed edges.
  • A node opens as a Tiptap document; in-progress is read-only with lockedBy.

Non-goals

Channels/live-push (V2.1) · global cross-project scope · Yjs co-editing.
