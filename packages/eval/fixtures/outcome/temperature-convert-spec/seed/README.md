# temperature

A tiny CommonJS module exposing `toFahrenheit(celsius)` — convert Celsius to Fahrenheit (`F = C * 9/5 + 32`).

Examples: `toFahrenheit(0)` → `32`, `toFahrenheit(100)` → `212`, `toFahrenheit(-40)` → `-40`.

`src/temperature.js` ships a stub that throws; implement it. Keep the CommonJS export
(`module.exports = { toFahrenheit }`). No dependencies.
